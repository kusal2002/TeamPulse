# TeamPulse Frontend (React 19 + TypeScript + Vite)

The frontend client application for **TeamPulse** - Weekly Report Generator & Team Dashboard.

---

## 🛠 Tech Stack
- **Framework**: React 19, Vite, TypeScript
- **Styling**: Tailwind CSS v4, Shadcn UI, Lucide Icons
- **State & Data**: TanStack React Query, React Router v7
- **Charts**: Recharts
- **Markdown & AI Chat**: React Markdown (Remark GFM)

---

## 📋 Setup Instructions

### 1️⃣ Install Dependencies
```bash
npm install
```

### 2️⃣ Development Server
```bash
npm run dev
```
Application runs at: `http://localhost:5173`

### 3️⃣ Production Build
```bash
npm run build
```
Output directory: `dist/`
